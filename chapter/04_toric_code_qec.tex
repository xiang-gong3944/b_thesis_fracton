\chapter{Toric code と量子誤り訂正}
この章では、量子誤り訂正符号の代表的な例として toric code を取り上げる。
これまで見てきた Shor 符号やスタビライザー形式の議論を踏まえ、
toric code が格子上に定義された局所スタビライザー符号として
どのように構成されるかを説明する。
とくに本章では、通常の qubit toric code に話を限り、
量子誤り訂正の言葉でその基本構造を理解することを目的とする。

toric code の重要性は、単に具体的な量子誤り訂正符号であるという点にとどまらない。
この符号では、スタビライザー、論理演算子、シンドローム、復号といった
量子誤り訂正の基本概念が、格子上のループや鎖の幾何学と直接結びついて表される。
そのため toric code は、量子誤り訂正の立場から見ても見通しがよく、
また後に見るホモロジー的構成や位相的秩序の理解への自然な入口ともなる。

本章では、まず toric code の定義と局所スタビライザー構造を説明する。
次に、非可縮ループによる論理演算子と、誤り鎖・シンドローム・等価類の関係を述べる。
そのうえで、復号問題と閾値現象の基本像を紹介し、
復号問題が統計力学的模型と結びつくことを見る。
最後に、境界を持つ場合の surface code との関係に簡単に触れる。

\section{Toric code の定義と局所スタビライザー構造}
前章では、スタビライザー形式によって量子誤り訂正符号を
可換な検査演算子の共通固有空間として記述できることを見た。
この見方に立つと、量子誤り訂正符号を考える際には、
単に符号空間が定義できるだけでなく、
それを定めるスタビライザーが物理的に実現しやすい形をしているかどうかが重要となる。
とくに量子メモリとして望ましいのは、
各サイトの自由度が有限であり、
スタビライザーが少数個の自由度にのみ作用する局所的な相互作用として書けて、
しかもその共通固有空間が非自明な論理自由度を持つような符号である。
そのような符号では、誤りの検出や励起の構造も局所的に記述しやすく、
物理模型としての解釈も与えやすい。

こうした要請を満たす最も基本的な例の1つが、
Kitaev によって導入された、格子上に定義される局所スタビライザー符号
Toric code である。
この符号では、量子ビットを格子の辺に配置し、
頂点と面に対応する局所的な検査演算子によって符号空間を定める。
その結果、論理演算子、シンドローム、誤りの等価類といった
量子誤り訂正の基本概念が、格子上のループや鎖の幾何学として
直接見える形であらわれる。

本節では、このToric codeを通常の qubit 系、
すなわち \(\mathbb{F}_2\) 上のスタビライザー符号として導入する。
まず格子と量子ビットの配置を定め、
ついでスタビライザー演算子を定義し、
それらが可換であることから符号空間が定まることを見る。
さらに、この符号が局所スタビライザー符号であると同時に
CSS 型の符号として理解できることを確認する。

まず、2次元の \(L_x\times L_y\) 正方格子をトーラス上に配置した系を考える。
すなわち、平面上の正方格子に周期境界条件を課し、
左右の端どうし、上下の端どうしをそれぞれ同一視した格子である。
Toric code では、この格子の各辺に1つずつ量子ビットを配置する。
したがって、自由度は頂点や面ではなく辺に属している。

この格子上に、頂点と面に対応する2種類の局所演算子を定義する。
各頂点 \(v\) に対して、その頂点に接続する4本の辺に作用する演算子
\begin{equation}
    A_v := \prod_{e\ni v} X_e
\end{equation}
を定める。
ここで \(X_e\) は辺 \(e\) 上の量子ビットに作用するパウリ \(X\) 演算子である。
同様に、各面 \(p\) に対して、その面の境界をなす4本の辺に作用する演算子
\begin{equation}
    B_p := \prod_{e\in \partial p} Z_e
\end{equation}
を定める。
ここで \(Z_e\) は辺 \(e\) 上の量子ビットに作用するパウリ \(Z\) 演算子であり、
\(\partial p\) は面 \(p\) の境界をなす辺の集合である。
以後、このように辺の集合 \(\gamma\) に沿って並んだ \(Z\) 演算子の積を
\begin{equation}
    Z(\gamma):=\prod_{e\in\gamma} Z_e
\end{equation}
のように書くことにする。
また、辺の集合の和 \(\gamma_1+\gamma_2\) は
\(\mathbb{F}_2\) 的な和、すなわち同じ辺が2回現れたら打ち消し合う和を表すものとする。
このとき
\begin{equation}
    Z(\gamma_1)Z(\gamma_2)=Z(\gamma_1+\gamma_2)
\end{equation}
が成り立つ。
したがって、plaquette 演算子は
\begin{equation}
    B_p = Z(\partial p)
\end{equation}
と表せる。
頂点に付随する \(A_v\) を star 演算子、面に付随する \(B_p\) を plaquette 演算子と呼ぶ。

これらの演算子は互いに可換である。
実際、2つの star 演算子どうし、あるいは2つの plaquette 演算子どうしは、
いずれもパウリ \(X\) 同士または \(Z\) 同士の積であるから可換である。
また、star 演算子 \(A_v\) と plaquette 演算子 \(B_p\) の組を考えると、
両者が共有する辺の本数は 0 本か 2 本である。
共有辺が 0 本ならば自明に可換であり、
共有辺が 2 本のときにも、各共有辺での反交換
\(
XZ=- ZX
\)
が2回現れるため、全体として符号は打ち消し合う。
したがって
\begin{equation}
    [A_v,B_p]=0
\end{equation}
が任意の \(v,p\) について成り立つ。

よって、これらの演算子の共通固有空間を考えることができる。
Toric code の符号空間は、
全ての頂点 \(v\) と面 \(p\) に対して
\begin{equation}
    A_v\ket{\psi}=\ket{\psi},\qquad
    B_p\ket{\psi}=\ket{\psi}
\end{equation}
を満たす状態全体として定義される。
すなわち、
\begin{equation}
    \mathcal{C}
    =
    \qty{
        \ket{\psi}
        \mid
        A_v\ket{\psi}=\ket{\psi},
        B_p\ket{\psi}=\ket{\psi},
        \forall v,p
    }
\end{equation}
である。

この定義から、Toric code は局所スタビライザー符号であることがわかる。
実際、スタビライザー群は \(\{A_v,B_p\}\) によって生成され、
各生成元は格子上のごく少数の量子ビットにしか作用しない。
前章で見た CSS 型スタビライザー符号の約束に従えば、
パウリ \(X\) の積で書かれる \(A_v\) は位相エラーを検出するスタビライザーであり、
パウリ \(Z\) の積で書かれる \(B_p\) はシフトエラーを検出するスタビライザーである。
したがって、Toric code は CSS 型スタビライザー符号の代表例でもある。

また、これらのスタビライザーを用いると
\begin{equation}
    H=- \sum_v A_v- \sum_p B_p
\end{equation}
という可換局所ハミルトニアンを定義できる。
ここで各 \(A_v,B_p\) はいずれも固有値 \(\pm 1\) を持つので、
エネルギーが最小になるのは全ての頂点と面について
\begin{equation}
    A_v\ket{\psi}=\ket{\psi},\qquad
    B_p\ket{\psi}=\ket{\psi}
\end{equation}
が成り立つときである。
このハミルトニアンの基底状態空間は上で定義した符号空間 \(\mathcal{C}\) に一致する。
したがって、Toric code は量子誤り訂正符号であると同時に、
可換局所模型としても理解することができる。

\section{論理演算子・誤り鎖・シンドローム}

前節では、Toric code を格子上に定義された局所スタビライザー符号として導入し、
その符号空間を star 演算子と plaquette 演算子の共通 \(+1\) 固有空間として定義した。
しかし、量子誤り訂正符号としてこの符号を理解するためには、
物理量子ビットに生じた誤りがどのように検出され、
その結果としてどのような論理自由度が残るのかを調べる必要がある。

Toric code の特徴は、これらの問いが格子上の図形を用いて
きわめて具体的に記述できる点にある。
まず誤りは辺に沿った鎖として表され、
さらに、シンドロームはその鎖の端点として読み取ることができる。
そのうえで、端点を持たない閉じた鎖のうち、
有限の領域の境界になっているものは stabilizer とみなせる一方、
トーラスを一周するものはそれとは異なる役割を果たす。
このようにして、誤り、シンドローム、論理演算子の関係が
同じ幾何学的な言葉で統一的に記述される。

本節では、まず位相エラー \(Z(\gamma)\) から生じる誤り鎖とシンドロームの描像を導入する。
次に、閉じた鎖のうち有限の領域の境界になっているものが stabilizer に対応することを見たうえで、
トーラスを一周するループから論理演算子を導入する。
最後に、前章で導入した \(N(S)/S\) の立場と結びつけながら
符号パラメータ \([[n,k,d]]\) を計算し、
復号問題が誤りそのものを当てる問題ではなく、
誤りの同値類を識別する問題として理解できることを見る。

誤り鎖の描像を導入するために、まず各辺の量子ビットが \(\ket{0}\) にある状態
\begin{equation}
    \ket{\Omega_0}=\bigotimes_e \ket{0}_e
\end{equation}
を考える。
この状態は各 plaquette 演算子 \(B_p\) に対して
\begin{equation}
    B_p\ket{\Omega_0}=\ket{\Omega_0}
\end{equation}
を満たす。
一方で、\(\ket{\Omega_0}\) は star 演算子 \(A_v\) の固有状態ではないため、
そのままでは符号空間には属していない。
そこで前章で導入したスタビライザーの射影演算子を用いて、
\(\ket{\Omega_0}\) を符号空間へ射影した状態
\begin{equation}
    \ket{\Omega}:=\frac{1}{\sqrt{\mathcal N}}
    \prod_v \frac{1+A_v}{2}\ket{\Omega_0}
\end{equation}
を基準状態として考える。
 この状態は全ての \(A_v\) と \(B_p\) に対して固有値 \(+1\) を持つので、
\(\ket{\Omega}\in\mathcal{C}\) である。

以下では、この基準状態に生じる位相エラー \(Z(\gamma)\) の効果を調べることから始める。
まず、1本の辺 \(e\) に沿ったエラーは
\begin{equation}
    Z(e)\ket{\Omega}=Z_e\ket{\Omega}
\end{equation}
と書ける。
このパウリ \(Z_e\) は、
その辺に接続する2つの頂点に対応する star 演算子とは反交換し、
それ以外の star 演算子とは可換である。
実際、辺 \(e\) の両端にある2つの頂点を \(v_1,v_2\) とすると、
\begin{equation}
    A_{v_1}Z(e)\ket{\Omega}=- Z(e)A_{v_1}\ket{\Omega}=- Z(e)\ket{\Omega},
    \qquad
    A_{v_2}Z(e)\ket{\Omega}=- Z(e)A_{v_2}\ket{\Omega}=- Z(e)\ket{\Omega}
\end{equation}
であり、他の頂点 \(v\neq v_1,v_2\) については
\begin{equation}
    A_v Z(e)\ket{\Omega}=Z(e)A_v\ket{\Omega}=Z(e)\ket{\Omega}
\end{equation}
となる。
したがって、1つの位相エラー \(Z(e)\) は2つの頂点で star 条件を破り、
その2点にシンドロームを生じさせる。

次に、隣接する2本の辺 \(e_1,e_2\) に位相エラーが入った状態
\begin{equation}
    Z(e_1+e_2)\ket{\Omega}
\end{equation}
を考える。
このとき、2本の辺が共有する頂点では反交換が2回起こるため符号が打ち消し合い、
その頂点ではシンドロームは消える。
一方で、鎖の両端にある頂点では反交換が1回だけ残るため、
そこにのみシンドロームが現れる。
このことから、複数の辺にわたる位相エラーは格子上の鎖として表され、
シンドロームはその鎖の端点として理解できることがわかる。

一般に、辺の集合 \(\gamma\) に沿って位相エラーが入った状態は
\begin{equation}
    Z(\gamma)\ket{\Omega}
\end{equation}
のように書ける。
このとき鎖の内部にある頂点では反交換が偶数回起こるためシンドロームは消え、
端点にあたる頂点だけが star 条件の違反として残る。
したがって、位相エラーは格子上の \(Z\)-鎖として表され、
そのシンドロームは鎖の端点によって与えられる。

とくに、\(\gamma\) が閉じた鎖であるときには端点が存在しないため、
\(Z(\gamma)\ket{\Omega}\) は star 条件の違反を生じない。
したがって、閉じた \(Z\)-鎖はシンドロームを持たない。
しかし、シンドロームを持たない閉じた鎖が全て同じ役割を果たすわけではない。

まず、\(\gamma\) が格子上のある有限の領域 \(R\) の境界 \(\partial R\) になっている閉ループである場合を考える。
このとき、その領域に含まれる plaquette 演算子の積を取ると、
内部の辺では各 \(Z_e\) が2回ずつ現れて打ち消し合い、
境界に沿う辺だけが1回ずつ残る。
したがって、\(\partial R\) に沿った閉ループ演算子は
\begin{equation}
    Z(\partial R)=\prod_{p\in R} B_p
\end{equation}
のように、その領域に含まれる plaquette 演算子の積として書ける。
すなわち、この種の閉ループは stabilizer の積にすぎない。
したがって、符号空間上では
\begin{equation}
    Z(\partial R)\ket{\psi}=\ket{\psi}
\end{equation}
が成り立ち、この種の閉ループは論理状態を変えない。

これに対して、\(\gamma\) がトーラスを一周してしまうような閉ループである場合には事情が異なる。
このようなループも閉じている以上シンドロームは生じないが、
もはやある有限領域の境界としては書けない。
したがって、そのような \(Z\)- ループは plaquette 演算子の積では表せず、
stabilizer 群には属さない。
それにもかかわらず、各 star 演算子 \(A_v\) とは可換であり、
また plaquette 演算子 \(B_p\) とも自明に可換である。
よって、そのような \(Z\)- ループは符号空間を保ちながら、
その内部で恒等的ではない作用をする演算子になっている。

このことは、前章で導入した正規化群 \(N(S)\) の言葉で言い直すことができる。
いま、トーラスを一周する \(Z\)- ループを \(\ell\) とすると、
対応する演算子 \(Z(\ell)\) は全てのスタビライザーと可換であるから \(N(S)\) に属する。
一方で、plaquette スタビライザー \(B_p=Z(\partial p)\) を掛けると
\begin{equation}
    Z(\ell)B_p = Z(\ell)Z(\partial p)=Z(\ell+\partial p)
\end{equation}
となる。
すなわち、スタビライザーを掛けることはループに境界を付け足すことに対応する。
より一般に、領域 \(R\) に含まれる plaquette の積を掛ければ
\begin{equation}
    Z(\ell)\prod_{p\in R} B_p = Z(\ell+\partial R)
\end{equation}
となり、\(Z(\ell)\) と \(Z(\ell+\partial R)\) は符号空間上で同じ作用を与える。
したがって、\(N(S)\) の元である2つの演算子 \(P,Q\) に対して、
\begin{equation}
    P \sim Q
    \qquad
    \xleftrightarrow{\text{def}}
    \qquad
    \exists S\in S \text{ such that } Q=PS
\end{equation}
という同値関係を入れることができる。
この関係のもとでは、スタビライザーを掛けることによって移り合う演算子どうしを同一視する。
いま見たように、\(Z(\ell)\) に plaquette スタビライザーの積を掛けることは、
ループ \(\ell\) に境界 \(\partial R\) を付け足して \(Z(\ell+\partial R)\) に移ることと同じである。
したがって、演算子の観点では「stabilizer を掛けて移り合うこと」が同値関係であり、
誤り鎖の観点では「境界になっている閉ループを加えること」が同値関係になっている。

論理演算子として本質的なのは個々の演算子そのものではなく、
\begin{equation}
    [Z(\ell)] = \qty{ Z(\ell+\partial R) \mid R:\text{領域}}
\end{equation}
のような、スタビライザー倍までまとめた演算子の類である。
これは \(Z(\ell)\) の同値類であり、こうした同値類全体が \(N(S)/S\) をなす。
群の言葉ではこれは剰余群であり、幾何学の言葉では
「ループどうしを境界でずらしただけなら同一視する」という考え方に対応している。
この後者の見方は、次章でより系統的に扱うことになる。

同じ議論はシフトエラーについても成り立つ。
そのために、まず dual lattice を導入する。
これまで量子ビットを配置してきた元の正方格子のことを primal lattice と呼ぶことにする。
これに対して dual lattice とは、各 plaquette の中心を頂点とし、
隣接する plaquette の中心どうしを結んだ格子である。
このとき、dual lattice の各辺は primal lattice のちょうど1本の辺と交差しており、
両者の間には1対1の対応がある。
したがって、primal lattice の辺に作用するパウリ \(X_e\) を、
dual lattice 上の1本の辺に沿った演算子としてみなすことができる。

いま、primal lattice の1本の辺 \(e\) にシフトエラー \(X_e\) が生じたとする。
この演算子は、その辺を境界に含む2つの plaquette 演算子と反交換し、
それ以外の plaquette 演算子とは可換である。
実際、辺 \(e\) を共有する2つの plaquette を \(p_1,p_2\) とすると、
\begin{equation}
    B_{p_1}X_e\ket{\Omega}= -X_eB_{p_1}\ket{\Omega}= -X_e\ket{\Omega},
    \qquad
    B_{p_2}X_e\ket{\Omega}= -X_eB_{p_2}\ket{\Omega}= -X_e\ket{\Omega}
\end{equation}
であり、他の plaquette \(p\neq p_1,p_2\) については
\begin{equation}
    B_pX_e\ket{\Omega}= X_eB_p\ket{\Omega}= X_e\ket{\Omega}
\end{equation}
となる。
したがって、1つのシフトエラーは2つの面で plaquette 条件を破る。
この2つの面は dual lattice では2つの頂点に対応しており、
\(X_e\) はそれらを結ぶ1本の dual edge に沿ったエラーとして表される。

一般に、dual lattice 上の辺の集合 \(\eta\) に沿って並んだ \(X\) 演算子の積を
\begin{equation}
    X(\eta):=\prod_{e^\ast\in\eta} X_{e(e^\ast)}
\end{equation}
と書くことにする。
ここで \(e(e^\ast)\) は dual edge \(e^\ast\) と交差する primal edge を表している。
複数の辺にわたって \(X\) エラーが並ぶと、
内部では反交換が打ち消し合い、端点に対応する面だけにシンドロームが残る。
よって、シフトエラーもまた dual lattice 上の鎖 \(\eta\) として表され、
そのシンドロームは鎖の端点によって与えられる。

さらに、\(X\)- 鎖が閉じたループになっている場合には、上と全く同じ分類が生じる。
有限の領域の境界になっている閉ループであれば、
それは対応する star 演算子の積として書ける。
一方、トーラスを一周してしまう閉ループは star 演算子の積では書けず、
符号空間上で恒等的ではない作用をする。

このように、primal lattice 上の \(Z\)- ループ \(Z(\ell)\) と、
dual lattice 上の \(X\)- ループ \(X(\eta)\) とは
ちょうど対をなして現れることがわかる。

以上より、論理演算子の候補として残るのは、
トーラスの2つの独立な方向に沿った \(Z\)-ループ2本と、
dual lattice 上の \(X\)-ループ2本である。
これらをそれぞれ
\begin{equation}
    \overline{Z}_1,\ \overline{Z}_2,\qquad
    \overline{X}_1,\ \overline{X}_2
\end{equation}
と書くことにする。
ここで、\(\overline{Z}_1\) と \(\overline{X}_1\) は1組目の論理量子ビットに対応するループ、
\(\overline{Z}_2\) と \(\overline{X}_2\) は2組目の論理量子ビットに対応するループである。

同じ組に属する \(\overline{Z}_i\) と \(\overline{X}_i\) は、
primal lattice と dual lattice のループが1回だけ交差するように選ぶことができる。
そのため、それらはただ1つの辺でパウリ \(Z\) と \(X\) が反交換することから
\begin{equation}
    \overline{Z}_i\overline{X}_i=-\overline{X}_i\overline{Z}_i
    \qquad (i=1,2)
\end{equation}
を満たす。
一方、異なる組に属するループどうしは交差しないように選べるため、
\begin{equation}
    [\overline{Z}_1,\overline{X}_2]=
    [\overline{Z}_2,\overline{X}_1]=
    [\overline{Z}_1,\overline{Z}_2]=
    [\overline{X}_1,\overline{X}_2]=0
\end{equation}
である。
したがって、これらは2つの論理量子ビット上のパウリ演算子と同じ交換関係を満たしている。

よって、符号空間の基底は \(\overline{Z}_1,\overline{Z}_2\) の固有値によって
\begin{equation}
    \overline{Z}_1\ket{a,b}_L = (-1)^a \ket{a,b}_L,\qquad
    \overline{Z}_2\ket{a,b}_L = (-1)^b \ket{a,b}_L
    \qquad (a,b\in\{0,1\})
\end{equation}
のように選ぶことができる。
この基底に対して \(\overline{X}_1\) は1つ目の論理量子ビットを反転し、
\(\overline{X}_2\) は2つ目の論理量子ビットを反転する。
したがって、これらは2つの論理量子ビット上のパウリ演算子と同じ代数を実現しており、
Toric code には2つの独立な論理量子ビットが符号化されている。

物理量子ビットの数 \(n\) は格子の辺の本数であり、
正方格子では水平方向と垂直方向にそれぞれ \(L_xL_y\) 本の辺があるため
\begin{equation}
    n=2L_xL_y
\end{equation}
である。
また、論理量子ビット数は
\begin{equation}
    k=2
\end{equation}
である。
さらに、符号距離 \(d\) はトーラスを一周するループのうち最短のものの長さで与えられるから、
\begin{equation}
    d=\min(L_x,L_y)
\end{equation}
となる。
とくに \(L_x=L_y=L\) の正方格子では
\begin{equation}
    [[n,k,d]]=[[2L^2,2,L]]
\end{equation}
である。

このように、Toric code では誤り鎖の端点がシンドロームとして観測され、
有限の領域の境界になっている閉ループは stabilizer として自明であり、
トーラスを一周するループだけが論理演算子として残る。
したがって、復号において本質的なのは誤りの位置を完全に当てることではなく、
与えられたシンドロームに対して元の誤りと同じ同値類に属する回復演算を見つけることである。
